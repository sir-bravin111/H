# 🐱🐭 Tom/Jerry Bot — Sir Bravin Edition

A multi-device WhatsApp bot base built with [Baileys](https://github.com/WhiskeySockets/Baileys).

## ✨ Features
- Multi-device support
- Pairing code + QR login
- Modular command system
- Auto-reconnect
- Sir Bravin branding (no typing indicator)
